# Life

Osobisty pulpit: kalendarz, zadania, finanse (z płatnościami cyklicznymi), nawyki i notatki.

- `src/` – źródła (`app.css`, `app.js`, `body.html`)
- `build.py` – buduje stronę do `docs/` (publikowane przez GitHub Pages) i wersję podglądu dla Claude
- `docs/` – gotowa strona; działa offline i instaluje się na telefonie jak aplikacja

Budowanie: `python3 build.py` (wymaga Pillow do ikon).
